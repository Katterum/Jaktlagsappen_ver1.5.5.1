# Jaktlaget 1.5.5.1 Stable

Korrigerad version av 1.5.5.

- Återställd färgkodning och statusinformation på hemsidan och historiksidan.
- Korrigerad registreringsknapp så texten stannar inom knappen.
- Datumfältet har samma bredd som övriga fält.
- Fritextfält visas när Annan plats väljs.
- Kassationsorsaker: Ej tjänligt, Trafikdödat, Självdött/rovdjursdödat och Annan orsak.
- Kalenderaktiviteter visas som separata kort.
- Behåller valbart djurslag på hemsidan, information, senaste chatt, jaktstatistik och övriga förbättringar.
